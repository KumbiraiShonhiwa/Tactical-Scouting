## 📌 Project Overview

This project combines **tactical insights** and **market value scouting** using publicly available football data. Instead of just identifying players with impressive raw stats, the system focuses on finding players who:

1. **Fit the tactical style** of a target team.
2. Are **potentially undervalued** in the transfer market.

The current scope is focused on **six Premier League teams** with distinct tactical identities:

* Manchester United
* Newcastle United
* Aston Villa
* Tottenham Hotspur
* Brighton & Hove Albion
* Crystal Palace

By analyzing tactical fit and cross-referencing it with market valuations, the project demonstrates how **data science and software engineering** can be applied to practical, real-world football scouting.

---

## 🎯 Main Aims

* **Data Collection** → Gather tactical and market value data from public sources (FBref, WhoScored, Transfermarkt).
* **Tactical Profiling** → Define unique tactical profiles for each of the six teams.
* **Player Analysis** → Use clustering and similarity models to identify players who match tactical requirements.
* **Undervaluation Detection** → Highlight players who fit tactically but are undervalued in the market.
* **Visualization & Reporting** → Present results through an interactive web-based dashboard with radar charts, scatter plots, and scouting recommendations.

## 🛠️ Tech Stack (Planned)

* **Backend**: Python (FastAPI / Flask), PostgreSQL (free tier), Scikit-learn (analysis).
* **Frontend**: React or Vue, TailwindCSS, Chart.js / D3.js for visualizations.
* **Hosting**: Vercel/Netlify (frontend), Render/Heroku/Railway (backend).
* **Version Control**: GitHub with CI/CD (GitHub Actions).
